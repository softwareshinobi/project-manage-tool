# 🚀 ProjectManager: A Modern Web-Based Management Suite

ProjectManager is a comprehensive, client-side application suite built with modern web technologies. It provides a series of interconnected tools for project and task management, all wrapped in a cohesive, responsive "Superhero" themed interface. This suite is designed to be a high-efficiency environment for managing workflows, from high-level project tracking to granular task creation.

---

## ✨ Core Features

The suite is composed of several interconnected modules:

* **Project CRUD Dashboard:** A centralized hub for all project management.
    * **Create, Read, Update, Delete (CRUD):** Full control over the project lifecycle.
    * **Inline Editing:** Edit project details directly within the data table for maximum efficiency.
    * **DataTables Integration:** Robust, client-side table management with sorting, searching, and pagination.
    * **Data Export:** Export the project list to CSV or Excel with a single click.
    * **Dynamic Progress Bars:** At-a-glance visual feedback on project status.

* **Task Management System:**
    * **Kanban Board:** A drag-and-drop interface to manage tasks across different states (Backlog, To-Do, In Progress, Completed).
    * **Multi-Project Support:** A dynamic dropdown allows users to switch between different project boards seamlessly.
    * **Detailed Task Views:** Pages to create, view, and edit individual tasks with fields for priority, effort, checklists, and comments.
    * **Real-time Notifications:** Modals and toasts provide instant feedback for actions like moving or creating tasks.

* **System Monitor:** A simple dashboard to display the real-time operational status of critical (stubbed) APIs.

* **Link Portal:** A centralized navigation page with quick-access cards to all major features of the application suite.

## 🎨 Design Philosophy

The entire suite is built on a consistent design system to ensure a seamless user experience.

* **Theme:** Bootswatch "Superhero" theme provides a modern, dark, and assertive aesthetic.
* **Typography:** A combination of 'Orbitron' for headers and 'Roboto Condensed' for body text ensures clarity and a tech-forward feel.
* **Responsiveness:** All pages are fully responsive and functional across desktop, tablet, and mobile devices.

---

## 🛠️ Technology Stack

This project is built entirely with client-side technologies, requiring no backend or server-side processing.

* **HTML5:** The structural foundation of all pages.
* **CSS3:** Custom styles for theming, layout, and responsiveness.
* **Bootstrap 5:** The core framework for UI components and responsive grid layout.
    * **Bootswatch:** Used for the "Superhero" theme.
* **JavaScript (ES6+):** Powers all application logic, interactivity, and data manipulation.
* **jQuery:** Utilized as a dependency for the DataTables library for powerful DOM manipulation.
* **DataTables.js:** A feature-rich library for creating interactive and advanced HTML tables.
    * **Buttons Extension:** Enables data export functionality (CSV, Excel).
* **Flatpickr:** A lightweight and powerful date/time picker for editable date fields.
* **Font Awesome:** Provides a comprehensive library of icons used throughout the user interface.
